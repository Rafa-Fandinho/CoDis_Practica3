Para executar o programa, abrir dúas terminais no directorio de base, e executar ./gradlew clean build nun deles.

Despois, executar na primeira terminal o servidor con ./gradlew runServer, e na segunda o cliente con ./gradlew runClient.

O resto de instruccións de funcionamento van a ser imprimidas por pantalla polo cliente. Hai opcións incluidas por defecto para facilitar os tests.
